# StatusPill

Petite pastille d'état en capitales, toujours avec son mot.

- **Le consommateur fournit** : l'état (`crit`, `warn`, `good`) et le mot (« Pic de charge », « Sous-charge », « Stable »).
- `crit` en `red` / `on-red`, `warn` en `warn` / `on-warn`, `good` en `good` / `on-good`.
- Jamais de pastille sans mot : la couleur seule ne suffit pas.
