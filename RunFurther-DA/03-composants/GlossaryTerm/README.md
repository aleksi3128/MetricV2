# GlossaryTerm

Une entrée du Lexique : l'abréviation en grand, sa définition dessous.

- **Le consommateur fournit** : le terme (`term`, `red`) et une définition d'une ou deux phrases (`label`, `fg-2`) qui dit ce que c'est et à quoi ça sert.
- Les mêmes définitions alimentent les infobulles : une seule source.
