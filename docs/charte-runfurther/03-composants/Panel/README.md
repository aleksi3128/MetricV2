# Panel

Conteneur de section : un titre en capitales, un indice discret à droite, puis le contenu.

- **Le consommateur fournit** : le titre (`panel-title`), un indice facultatif (`fg-3`, 12 px), le contenu.
- Fond `surface`, filet `line`, rayon `radius-panel`, rembourrage `space-6`, écart `space-5` entre l'en-tête et le contenu.
- Un panneau par question : « Planning », « Dernière séance », « Volume hebdomadaire ». Pas de panneau dans un panneau.
- À éviter : une ombre, un filet coloré sur le côté.
