# RaceCountdown

Compte à rebours de la prochaine course objectif, en haut à droite de l'en-tête.

- **Le consommateur fournit** : le nombre de jours (`J-6`, « JOUR J » le jour même), le nom de la course, une ligne distance · date · objectif, l'infobulle avec le plan de course.
- Le compte à rebours est en `countdown`, `red` ; le cadre en `red-line`.
- Un seul compte à rebours : la course de priorité A la plus proche.
