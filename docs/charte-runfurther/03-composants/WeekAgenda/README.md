# WeekAgenda

La semaine en cours en liste, dans la colonne latérale : un jour par ligne, sa séance et son type.

- **Le consommateur fournit** : pour chaque jour, l'abréviation et le numéro (`day-number`), le nom de la séance, la ligne d'état (type, ou « Réalisé · 5,0 km »), l'infobulle de la séance.
- Aujourd'hui : bordure `red`. Jour de course : fond `red-soft`, bordure `red-line`.
- Un jour sans séance affiche « Libre ».
